# 389. Find the Difference

## LeetCode

* **Difficulty:** Easy
* **Topics:** String, Hash Table, Counting

---

## Problem Statement

You are given two strings `s` and `t`.

String `t` is generated by randomly shuffling string `s` and then adding one extra character.

Return the character that was added.

---

## My Approach

1. Merge both strings into a single string.
2. Convert the merged string into an array using `Array.from()`.
3. Build a frequency map using `reduce()`.
4. Find the character whose frequency is `1`.
5. Return that character.

---

## Complexity Analysis

**Time Complexity:** `O(n)`

* Creating the merged string: `O(n)`
* Building the frequency map: `O(n)`
* Traversing the frequency object: `O(k)` where `k` is the number of unique characters.

Overall: **O(n)**

**Space Complexity:** `O(k)`

* The frequency object stores the unique characters.
